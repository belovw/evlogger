# EV Logger (этап 1)

Логгер ELM327 (Bluetooth) для разведки данных Deepal S07.

## Как получить APK без Android Studio
1. Зарегистрируйся на github.com, создай новый репозиторий (New repository, имя evlogger).
2. Нажми "uploading an existing file" и перетащи ВСЁ содержимое распакованной папки,
   включая скрытую папку `.github` (если её не видно, включи показ скрытых файлов).
3. Commit changes. Открой вкладку Actions: пойдёт сборка "Build APK" (3-6 минут).
4. Когда будет зелёная галочка, открой запуск, внизу в Artifacts скачай `EvLogger-apk`,
   распакуй zip, внутри `app-debug.apk`. Установи на телефон (разреши установку из неизвестных источников).

## Использование
1. В настройках Bluetooth телефона спарь ELM327 (PIN обычно 1234 или 0000).
2. Открой приложение, разреши Bluetooth, геолокацию, уведомления.
3. Выбери адаптер, "Подключиться". Включи зажигание/READY.
4. "Старт записи лога", едь. Лог пишется в CSV, экран можно гасить.
5. "Отправить файл" и пришли его в чат.

## Свои PID
Список опрашиваемых PID лежит в `app/src/main/assets/pids.txt` (формат описан в файле).
Либо положи свой `pids.txt` в папку приложения на телефоне: Android/data/com.evlogger/files/.

## CAN-монитор
Пишет сырые кадры (ATMA) в can_*.txt. Делай записи короткими (30-60 секунд) и по сценарию:
например 20 с покоя, затем включить режим ДВС, потом выключить. Записывай, что и когда делал.
